Matrix Weather Clock installer

Flash the firmware to the Seengreat RGB Matrix HUB75 S3 board straight from this page. Version ….

  1. Use Chrome or Edge on a computer (Web Serial is not available in Firefox, Safari or on phones).
  2. Connect the board's programming USB-C port (not the panel-power port) to the computer.
  3. Click Install, pick the board's serial port, and wait for the progress bar to finish. Choose "erase" on a first install.
  4. The panel plays a test pattern, then starts the MatrixWeatherClock-XXXX WiFi network. Join it and open http://4.3.2.1/ to finish setup.

This browser cannot access serial ports. Use Chrome or Edge on Windows, macOS, Linux or ChromeOS. Serial access needs a secure page: open this installer over HTTPS or from http://localhost.

If the port does not appear: hold BOOT, tap RST, release BOOT, then click Install again. Later updates can be uploaded from the clock's own web page (Update tab) using the OTA image below.
